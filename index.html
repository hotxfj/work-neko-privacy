打工小猫隐私政策

本政策适用于 Microsoft Store 版「打工小猫」（原提交名称为「打工人专属小猫」）及其应用内的背后检测 Pro。版本日期：2026 年 11 月 22 日。

应用使用的数据

  • 开始录音时，应用读取你所选麦克风的声音。开始录像时，应用读取你所选摄像头和麦克风的内容。录音和录像保存到本机，录制时小猫旁显示状态指示。
  • Pro 背后检测默认关闭。获得授权并开启后，应用读取摄像头画面，在本机判断画面中是否有人。录入本人会保存供比对的人脸及外观特征。触发提醒时，应用最多滚动保存最近 50 张本地快照。
  • 应用在本机保存设置和便签。剪贴板历史须手动开启，近期文本仅留在本次运行的内存中，关闭功能或退出应用时清空。
  • 购买、恢复购买及 Pro 许可证核验由 Microsoft Store 处理。应用读取许可状态，支付信息由 Microsoft 处理。

存储和使用

摄像头画面、录音、录像、提醒快照、人脸特征、便签和剪贴板文本由应用在本机处理。应用不会把这些内容发送给开发者或第三方，也不会用它们投放广告。能够访问你 Windows 账户和本机文件的人可能访问相关本地文件。

你的选择

可从托盘菜单停止录音、录像或背后检测。在「背后检测（Pro）」里可撤回摄像头授权，并在「本人数据」中删除已录入特征。在「报警记录」及录音、录像目录中可查看和删除本地文件。你也可以在 Windows 的隐私设置中管理摄像头和麦克风访问。

仅在有权使用设备并已告知相关人员的场合使用录制或检测功能。需要联系开发者时，请使用 Microsoft Store 商品页面提供的支持渠道。
